# Triage-Labels

Deutsche Fassung von [triage-labels.md](triage-labels.md). Maßgeblich für die Agent-Skills ist die englische Datei; bei Änderungen beide anpassen.

Die Skills sprechen von fünf festen Triage-Rollen. Diese Tabelle ordnet ihnen die Label-Namen in unserem Tracker zu.

| Label in mattpocock/skills | Label bei uns       | Bedeutung                                     |
| -------------------------- | ------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`      | Maintainer muss das Issue bewerten            |
| `needs-info`               | `needs-info`        | Wartet auf weitere Angaben der meldenden Person |
| `ready-for-agent`          | `ready-for-agent`   | Vollständig beschrieben, bereit für einen Agenten |
| `ready-for-human`          | `ready-for-human`   | Muss von einem Menschen umgesetzt werden      |
| `wontfix`                  | `wontfix`           | Wird nicht umgesetzt                          |
