# Pack-/Mitbringliste

Im Admin-Bereich das gewünschte Event wählen und unter **Admin → Infos → Pack-/Mitbringliste** den Text eintragen. Mit **Infos speichern** sichern.

Die Liste gehört nur zu diesem Event. Bis zu 10000 Zeichen sind erlaubt; Zeilenumbrüche und Leerraum bleiben erhalten. Die Anzeige ist reiner Text, ohne Markdown, interaktive Checkboxen oder persönliche Abhakstände. Es werden keine Listeneinträge vorgegeben.

Unter **Infos** erscheint die Karte nur, wenn der Text nicht leer ist bzw. nicht ausschließlich aus Leerraum besteht. Zum Ausblenden das Feld leeren und speichern. Es gelten die bestehenden Modul- und Ticket-Zugriffsregeln des Info-Bereichs; die Liste hat keine eigene Sichtbarkeitseinstellung.

Bestehende Events ohne gespeichertes Feld liefern eine leere Liste. Das Lesen ergänzt keine Daten in SQLite; eine Schema-Migration ist nicht erforderlich.
